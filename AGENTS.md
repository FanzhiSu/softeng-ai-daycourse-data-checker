# Agent working boundary for this course

This repository is used for a software-engineering teaching exercise.

When asked to make changes during the course:

- Work in the working tree only.
- Do not stage or commit changes.
- Do not push changes.
- Do not create GitHub issues or pull requests.
- Do not merge anything.
- Run tests when requested, but leave the final repository actions to the human.

The human participant should inspect the diff and decide what enters Git history or the shared repository.
