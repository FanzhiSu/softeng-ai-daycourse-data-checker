# Agent working boundary for this course

This repository is used for a software-engineering teaching exercise.

When asked to make changes during the course:

- Work in the working tree only.
- Do not stage or commit changes.
- Do not push changes.
- Do not create GitHub issues or pull requests.
- Do not merge anything.
- Run tests when requested, but leave the final repository actions to the human.

The human participant should inspect the diff and decide what enters Git history or the shared repository.

# Testing and verification

- Do not create, modify or delete automated tests unless explicitly requested.
- Do not introduce new testing frameworks or dependencies.
- You may run existing tests to check for regressions.
- For implementation tasks, report how the changed behaviour can be
  verified manually.

When asked to write or modify tests, follow the specific instructions for that task.

# Scope of changes

- Make only the changes needed for the requested task.
- Avoid unrelated refactoring or dependency changes.
- If additional work appears necessary, explain why before proceeding.
